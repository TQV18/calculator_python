# 🧮 Simple Calculator

A simple calculator application developed using **Python** and **CustomTkinter**, featuring a modern dark-mode interface and support for basic arithmetic operations.

---

---

## ✨ Features
- Basic arithmetic operations: `+`, `-`, `*`, `/`
- Decimal number support
- Percentage (%) calculations
- Dark mode interface
- Clean and user-friendly design

---

## 🛠️ Technologies Used
- Python 3
- CustomTkinter

---

## ▶️ How to Run

### 1. Install Python
Make sure you have **Python 3.x** installed.

### 2. Install required library
```bash
pip install customtkinter
```
